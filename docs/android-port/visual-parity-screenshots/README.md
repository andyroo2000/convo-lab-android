# Pixel visual parity captures

Pixel 10a, Android 16, 1080 × 2424; isolated test account data only.
Captured during the 2026-11-21 parity pass. Content may differ from the iOS
fixtures; compare layout, typography, colors, and control placement.

The correction, menu, and player fixtures intentionally isolate those components.
The final-text fixture does not mount an audio coordinator; production places the
player between the version toolbar and final paper. Full notebook/editor and
conversation captures exercise the containing layout and keyboard insets.
